# java-racingcar-precourse

# 기능 목록

## 1. 테스트코드 작성
- [x] 테스트코드 작성

## 2. 입력 기능
- [x] 자동차 이름 입력받기
    - [x] 쉼표(,)를 기준으로 자동차 이름 분리
    - [x] 각 자동차 이름의 앞뒤 공백 제거

- [x] 시도 횟수 입력받기
    - [x] 문자열을 정수로 변환

## 3. 입력 검증 기능
- [ ] 자동차 이름 유효성 검증
    - [ ] 자동차 이름이 빈 문자열인지 검증
    - [ ] 자동차 이름이 5자를 초과하는지 검증
    - [ ] 중복된 자동차 이름이 있는지 검증

- [ ] 시도 횟수 유효성 검증
    - [ ] 시도 횟수가 숫자인지 검증
    - [ ] 시도 횟수가 양수인지 검증

## 4. 자동차 기능
- [ ] 자동차 객체 생성
    - [ ] 이름 저장
    - [ ] 위치(이동 거리) 초기화 (0)

- [ ] 자동차 전진 기능
    - [ ] 0~9 사이의 무작위 값 생성
    - [ ] 무작위 값이 4 이상이면 전진
    - [ ] 현재 위치 반환

## 5. 경주 게임 기능
- [ ] 경주 게임 초기화
    - [ ] 자동차 목록 생성

- [ ] 경주 진행
    - [ ] 주어진 횟수만큼 라운드 반복
    - [ ] 각 라운드마다 모든 자동차 이동 시도
    - [ ] 각 라운드 결과 출력

- [ ] 우승자 결정
    - [ ] 모든 자동차 중 최대 이동 거리 찾기
    - [ ] 최대 이동 거리를 가진 자동차 찾기
    - [ ] 우승자가 여러 명인 경우 처리

## 6. 출력 기능
- [ ] 실행 결과 출력
    - [ ] "실행 결과" 문구 출력
    - [ ] 각 라운드마다 빈 줄 출력

- [ ] 자동차 상태 출력
    - [ ] 자동차 이름 출력
    - [ ] " : " 구분자 출력
    - [ ] 이동 거리만큼 "-" 출력

- [ ] 최종 우승자 출력
    - [ ] "최종 우승자 : " 문구 출력
    - [ ] 우승자가 여러 명인 경우 쉼표(,)로 구분하여 출력

## 7. 예외 처리
- [ ] IllegalArgumentException 발생 시 애플리케이션 종료
    - [ ] 유효하지 않은 자동차 이름 입력
    - [ ] 유효하지 않은 시도 횟수 입력
